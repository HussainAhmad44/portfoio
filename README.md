# Hussain Ahmad — Premium Portfolio

A responsive, animated portfolio website with project illustrations, sections for skills, research, education, certificates and contact.

## Run
Open `index.html` in a browser. No build tools required. Optionally use the VS Code Live Server extension.

## Customize
Edit content in `index.html`, colors and layout in `style.css`, and interactions in `script.js`.

## Notes
- The hero image (`assets/concept.png`) is an AI-generated **concept illustration**, not a real photograph of Hussain or a screenshot of an application.
- Project visuals are stylized CSS illustrations, not verified project screenshots.
- Project descriptions represent the supplied portfolio information; unpublished research is explicitly labeled ongoing.
- Google Fonts are loaded online; fallback fonts work offline.
- Project links are included only where a known repository exists.
